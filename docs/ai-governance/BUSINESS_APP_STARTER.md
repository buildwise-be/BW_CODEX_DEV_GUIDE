# Business App Starter

Le dépôt actuel reste le framework de gouvernance Codex pour les projets de développement spécifiques. Le pilote applicatif se trouve dans `starter/` sur la branche `codex/business-app-starter`.

Le starter est conçu pour devenir un dépôt GitHub Template autonome nommé `bw-app-starter`. Il fournit un socle React/TypeScript/Vite, une interface Buildwise, deux modèles métier, des données de démonstration, un contrat d’adaptateur de données et un parcours Codex orienté mission business.

Les fichiers de gouvernance du framework et les fichiers du starter ont des responsabilités différentes : les premiers encadrent l’adoption dans les dépôts, les seconds servent directement à construire une application.
