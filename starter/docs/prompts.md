# Prompts métier

## Décrire une nouvelle fonctionnalité

> Je veux aider [utilisateur] à [mission]. Aujourd’hui [problème]. Il doit pouvoir [action] avec [données]. Le résultat sera réussi si [critère]. Commence par reformuler le besoin et propose une première version simple.

## Demander une validation

> Vérifie cette fonctionnalité du point de vue d’un utilisateur métier. Signale ce qui est clair, ce qui peut bloquer la décision et ce qu’il faut tester.

## Préparer une connexion de données

> Remplace les données de démonstration par une source réelle en conservant l’interface. Commence par identifier le contrat de données et les états d’erreur avant de modifier le code.
