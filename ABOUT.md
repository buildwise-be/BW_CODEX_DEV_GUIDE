# Buildwise App Builder

Framework de construction d'applications piloté par le métier dans Codex.
Base : contenu src/ du BW Codex Development Framework V2, commit 302aedc.
Le socle de gouvernance est à la racine ; le futur src/ est réservé à l'application.
Ce dépôt n'est pas un service d'exécution autonome en arrière-plan : Codex réalise les tâches pendant les sessions autorisées.
