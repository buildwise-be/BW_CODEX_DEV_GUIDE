Palette observée : bleu #0087B7, turquoise #00BFB6, texte #1B1B1B,

Police du site : Neue Haas Unica. Aucun fichier propriétaire n'est distribué.
La pile locale utilise cette police si installée, sinon Arial/Helvetica.
Les droits de distribution des logos/polices pour un template public doivent être
confirmés avec Buildwise ; la page des logos précise des conditions d'utilisation.

Utiliser le logo sur fond clair, conserver ses proportions et une zone libre.
Pas de filtre, déformation, recoloration ou logo de substitution.
Le thème fourni constitue une base d'interface, pas une certification complète de charte.
