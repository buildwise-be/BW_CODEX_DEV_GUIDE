# Références Buildwise

Règles obligatoires : docs/ai-governance/BRAND_RULES.md.
Les ressources sont verrouillées par empreinte dans policy.json. Les nouvelles
applications réutilisent ces fichiers et passent scripts/check-brand.mjs.
Ne modifier ni la référence ni son empreinte sans décision graphique explicite.

Sources officielles consultées le 2026-09-03 :
- https://www.buildwise.be/fr/logos/
- https://www.buildwise.be/assets/images/icons.svg (symbole logo)
- https://www.buildwise.be/assets/css/main.css

Logo vectoriel extrait sans redessiner les tracés, stocké dans buildwise-logo.svg.
Palette observée : bleu #0087B7, turquoise #00BFB6, texte #1B1B1B,
gris clair #F2F2F2. Les variantes d'interface sont des adaptations, pas des
couleurs supplémentaires certifiées par une charte interne.

Police observée sur le site : Neue Haas Unica. Police des applications : Roboto,
demandée par l'utilisateur le 2026-09-04. La pile locale utilise Roboto si installé,
sinon Arial/Helvetica ; aucun fichier de police n'est actuellement distribué.
Spécifications chiffrées : docs/ai-governance/UI_SPEC.md.
Les droits de distribution des logos/polices pour un template public doivent être
confirmés avec Buildwise ; la page des logos précise des conditions d'utilisation.

Utiliser le logo sur fond clair, conserver ses proportions et une zone libre.
Pas de filtre, déformation, recoloration ou logo de substitution.
Le thème fourni constitue une base d'interface, pas une certification complète de charte.
