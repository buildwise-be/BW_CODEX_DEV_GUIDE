# Optional examples

This directory contains two demonstration views: project tracking and a KPI dashboard. They are not a predefined application.

Inspect them only when the approved brief makes them relevant or when the user explicitly asks to explore examples. The historical interface has not yet been fully aligned with the current Buildwise brand rules, so it is not a visual source of truth. Use the root `assets/brand/` resources instead.

Build and tests are not certified at this stage. From this directory, use `npm install` and `npm run dev` for exploratory maintenance only.
